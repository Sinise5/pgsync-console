MIGRASI WAL2JSON - FILE CHANGES SUMMARY
========================================

MODIFIED FILES:
Dockerfile.base      - Baked-in patch untuk wal2json (build-time)
Dockerfile           - Hapus runtime patch call
docker-compose.yml   - Hapus runtime patch dari bootstrap & cdc
Makefile             - Slot: pgoutput -> wal2json, publication dihapus
scripts/patch-pgsync-plugin.sh - Full wal2json compatibility

CREATED FILES:
scripts/patch-pgsync-baked.py - Build-time patch script
MIGRATION-WAL2JSON.md - Dokumentasi lengkap + rollback
QUICKSTART.md - Step-by-step execution guide
validate-migration.sh - 7 post-migration checks
migration-to-wal2json.sh - Automated migration script

FILES DELETED:
(none - patch plugin script retained for manual use)

ROOT CAUSE FIXED:
PGSync 7.0.5 parser expect TEXT format -> pgoutput=BINARY -> UnicodeDecodeError
Fix: wal2json plugin = text JSON output, kompatibel dengan parser.

EXECUTION (di server dgn Docker):
1. Install wal2json di PG: sudo apt-get install postgresql-15-wal2json
2. Drop old slot: pg_drop_replication_slot('siitpartisi_laporan')
3. Create new slot: pg_create_logical_replication_slot('...','wal2json')
4. Build: docker build --no-cache -f Dockerfile.base -t pgsync-laporan:base .
5. Build: docker build --no-cache -t pgsync-laporan:app .
6. Start: docker compose up -d laporan-cdc
7. Validate: bash validate-migration.sh
