MIGRASI TEST_DECODING - FINAL SOLUTION
=======================================

ROOT CAUSE ANALYSIS
-------------------
1. pgoutput (binary protocol) -> UnicodeDecodeError: 'utf-8' codec can't decode byte 0xf0
2. wal2json (JSON format) -> LogicalSlotParseError: No match for row: {"change":[...]}
3. PGSync 7.0.5 parser built for test_decoding TEXT format (BEGIN 12345, table: INSERT: col[type] val)

SOLUTION
--------
Plugin: test_decoding (built-in PostgreSQL 15, no extension needed)
Patch: Remove options={"include-xids":"1"} yang tidak support di PG15

WHY TEST_DECODING
-----------------
✅ Built-in PostgreSQL 15 - tidak perlu install extension
✅ Text format - PGSync parser sudah dibuat untuk ini
✅ Regex match TX_BOUNDARY_RE, LOGICAL_SLOT_SUFFIX work out-of-box
✅ Production-stable sejak PostgreSQL 9.4
